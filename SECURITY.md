# Security Policy

## Reporting a Vulnerability

If you find a security vulnerability, **do not open a public issue**.

Send it directly to: **juanyamels@gmail.com**

Wait for a response before disclosing the finding.

## Scope

- `backend/` — API, authentication, data handling
- `frontend/` — Token storage, key exposure
- `cli/` — Terminal code execution

## Responsible disclosure

We report verified vulnerabilities within 7 business days. We appreciate any responsible report.
