#!/usr/bin/env # 🔧 Troubleshooting Guide\n\nCommon issues and how to solve them.\n\n## Development Setup Issues\n\n### Node.js Installation\n\n**Problem:** `npm: command not found`\n\n**Solution:**\n```bash\n# Install Node.js from https://nodejs.org/\n# Verify installation\nnode --version\nnpm --version\n```\n\n### PostgreSQL Connection Error\n\n**Problem:** `Error: connect ECONNREFUSED 127.0.0.1:5432`\n\n**Solution:**\n```bash\n# macOS (Homebrew)\nbrew services start postgresql\n\n# Linux (systemd)\nsudo systemctl start postgresql\n\n# Windows\n# Use PostgreSQL installer GUI or Services app\n\n# Verify connection\npsql postgres -U postgres\n```\n\n### Port Already in Use\n\n**Problem:** `Error: listen EADDRINUSE: address already in use :::4000`\n\n**Solution:**\n```bash\n# Find process using port 4000\nlsof -i :4000\n\n# Kill the process\nkill -9 <PID>\n\n# Or use a different port\nPORT=5000 npm run dev\n```\n\n### Database Migration Failed\n\n**Problem:** `Error: migration could not be applied cleanly`\n\n**Solution:**\n```bash\n# Check migration status\nnpx prisma migrate status\n\n# Reset database (WARNING: deletes all data)\nnpx prisma migrate reset\n\n# Or rollback specific migration\nnpx prisma migrate resolve --rolled-back \"migration_name\"\n```\n\n### Module Not Found\n\n**Problem:** `Error: Cannot find module 'react'`\n\n**Solution:**\n```bash\n# Clear cache and reinstall\nrm -rf node_modules package-lock.json\nnpm install\n\n# Clear npm cache\nnpm cache clean --force\n```\n\n---\n\n## Backend Issues\n\n### Environment Variables Not Loading\n\n**Problem:** `process.env.DATABASE_URL is undefined`\n\n**Solution:**\n```bash\n# Check .env file exists\nls -la backend/.env\n\n# Verify format (no quotes, no spaces)\nDATABASE_URL=postgresql://user:pass@localhost/db\n\n# Restart server\nnpm run dev\n```\n\n### API Returns 401 Unauthorized\n\n**Problem:** `{ \"error\": \"Token expired or invalid\" }`\n\n**Solution:**\n```bash\n# Check token in Authorization header\nAuthorization: Bearer <token>\n\n# Verify JWT_SECRET matches\n# Check token expiration time\n# Request new token from /api/auth/login\n```\n\n### Prisma Schema Out of Sync\n\n**Problem:** `Error: Database schema is out of sync`\n\n**Solution:**\n```bash\n# Generate Prisma client\nnpx prisma generate\n\n# View schema changes\nnpx prisma migrate diff\n\n# Apply pending migrations\nnpx prisma migrate deploy\n```\n\n### OpenRouter API Errors\n\n**Problem:** `Error: Invalid API key or rate limit exceeded`\n\n**Solution:**\n```bash\n# Check API key\necho $OPENROUTER_API_KEY\n\n# Verify key has credits at https://openrouter.ai\n\n# Check rate limits\ncurl -H \"Authorization: Bearer $OPENROUTER_API_KEY\" \\\n  https://openrouter.ai/api/v1/auth/key\n\n# Use different model if current one is overloaded\n```\n\n### Streaming Response Not Working\n\n**Problem:** Chat responses not streaming, just waiting\n\n**Solution:**\n```bash\n# Check WebSocket connection\n# Verify headers: Content-Type: application/json\n\n# Check backend logs\nnpm run dev\n\n# Test with curl\ncurl -X POST http://localhost:4000/api/chat/stream \\\n  -H \"Authorization: Bearer <token>\" \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\"content\": \"Hello\"}'\n```\n\n---\n\n## Frontend Issues\n\n### Next.js Build Fails\n\n**Problem:** `Error: Build failed with 1 validation error`\n\n**Solution:**\n```bash\n# Check TypeScript errors\nnpm run type-check\n\n# Fix errors and rebuild\nnpm run build\n\n# Check for unused imports\nnpm run lint\n```\n\n### API Connection Error\n\n**Problem:** `Failed to fetch from http://localhost:4000`\n\n**Solution:**\n```bash\n# Verify backend is running\ncurl http://localhost:4000/health\n\n# Check NEXT_PUBLIC_API_URL in .env.local\nNEXT_PUBLIC_API_URL=http://localhost:4000\n\n# Restart frontend\nnpm run dev\n```\n\n### Images Not Loading\n\n**Problem:** `img src broken` or 404 errors\n\n**Solution:**\n```bash\n# Check image path\n# Verify file exists in /public\nls -la frontend/public/images/\n\n# Update image path\n<Image \n  src=\"/images/image.png\" \n  alt=\"description\" \n  width={300} \n  height={300} \n/>\n```\n\n### State Not Persisting\n\n**Problem:** Zustand store resets on refresh\n\n**Solution:**\n```typescript\n// Add persistence\nconst useStore = create<Store>()(  \n  persist(\n    (set) => ({...}),\n    { name: 'store-name' }  // LocalStorage key\n  )\n);\n```\n\n### Styling Issues (Tailwind)\n\n**Problem:** Tailwind classes not applying\n\n**Solution:**\n```bash\n# Verify tailwind.config.ts includes all paths\ncontent: [\n  './src/app/**/*.{js,ts,jsx,tsx}',\n  './src/components/**/*.{js,ts,jsx,tsx}',\n]\n\n# Rebuild\nnpm run dev\n```\n\n---\n\n## CLI (Daya Code) Issues\n\n### CLI Won't Install\n\n**Problem:** `npm install -g daya-code` fails\n\n**Solution:**\n```bash\n# Update npm\nnpm install -g npm@latest\n\n# Install with sudo (if needed)\nsudo npm install -g daya-code\n\n# Or install from source\ncd cli\nnpm install -g .\n```\n\n### Authentication Failed\n\n**Problem:** `Error: Invalid token`\n\n**Solution:**\n```bash\n# Login again\ndaya-code login\n# Paste token from Settings → API Tokens\n\n# Check saved token\ncat ~/.daya/config.json\n\n# Or set env variable\nexport DAYA_TOKEN=\"your_token\"\ndaya-code \"your task\"\n```\n\n### Agent Not Finding Files\n\n**Problem:** `Error: File not found` when editing\n\n**Solution:**\n```bash\n# Run from project root\ncd ~/my-project\ndaya-code \"task\"\n\n# Check git status\ngit status\n\n# Try with absolute path\ndaya-code --yes \"edit ./src/file.ts\"\n```\n\n### Commands Won't Execute\n\n**Problem:** `Error: Permission denied` or command fails\n\n**Solution:**\n```bash\n# Check permissions\nls -la ~/.daya/\n\n# Approve permissions\n/permissions allow\n\n# Or approve all (not recommended)\ndaya-code --yes \"task\"\n```\n\n---\n\n## Deployment Issues\n\n### Railway Deployment Failed\n\n**Problem:** Build fails on Railway\n\n**Solution:**\n```bash\n# Check Railway logs\nrailway logs\n\n# Verify environment variables\nrailway variables\n\n# Common issues:\n# 1. Missing DATABASE_URL → Add to Railway variables\n# 2. Migration failed → Run: npx prisma migrate deploy\n# 3. Port not set → Add: PORT=4000\n```\n\n### Vercel Deployment Failed\n\n**Problem:** Deployment error on Vercel\n\n**Solution:**\n```bash\n# Check build logs in Vercel dashboard\n# Verify env variables have NEXT_PUBLIC_ prefix\n\n# Test locally\nnpm run build\n\n# Common issues:\n# 1. TypeScript errors → Run: npm run type-check\n# 2. Missing files → Check git status\n# 3. Env variables → Verify in Vercel dashboard\n```\n\n### Database Connection in Production\n\n**Problem:** `Error: connect ECONNREFUSED` in production\n\n**Solution:**\n```bash\n# Verify DATABASE_URL in production\nrailway variables\n\n# Test connection\npsql $DATABASE_URL -c \"SELECT 1;\"\n\n# Check IP whitelist (if applicable)\n# Verify TLS settings\n```\n\n---\n\n## Performance Issues\n\n### Slow Database Queries\n\n**Problem:** API responses taking 5+ seconds\n\n**Solution:**\n```sql\n-- Check slow queries\nSELECT query, calls, total_time FROM pg_stat_statements \nORDER BY total_time DESC LIMIT 10;\n\n-- Add indexes\nCREATE INDEX idx_messages_user_id ON \"Message\"(\"userId\");\nCREATE INDEX idx_documents_user_id ON \"Document\"(\"userId\");\n```\n\n### High Memory Usage\n\n**Problem:** Node process using 1GB+ RAM\n\n**Solution:**\n```bash\n# Monitor memory\nnode --max-old-space-size=4096 server.js\n\n# Check for memory leaks\n# Use: clinic.js or autocannon\n\n# Update dependencies\nnpm update\n```\n\n### Streaming Lag\n\n**Problem:** Chat streaming is slow/chunky\n\n**Solution:**\n```bash\n# Check network:\n# - Open DevTools → Network tab\n# - Look for high latency\n\n# Reduce chunk size\n# - Verify OpenRouter connection\n# - Check backend CPU usage\n```\n\n---\n\n## Security Issues\n\n### Exposed API Keys\n\n**Problem:** API key committed to GitHub\n\n**Solution:**\n```bash\n# Remove from history\ngit filter-branch --tree-filter 'rm -f .env' -f\n\n# Rotate API keys immediately\n# Push forced update\ngit push -f\n\n# Add to .gitignore\necho \".env\" >> .gitignore\n```\n\n### CORS Errors\n\n**Problem:** `Access to XMLHttpRequest blocked by CORS`\n\n**Solution:**\n```typescript\n// Backend: Configure CORS\napp.use(cors({\n  origin: process.env.FRONTEND_URL,\n  credentials: true\n}));\n```\n\n### Missing HTTPS\n\n**Problem:** `Error: Insecure connection`\n\n**Solution:**\n```bash\n# Vercel: Automatic HTTPS\n# Railway: Enable HTTPS in settings\n# Local: Use http://localhost only\n```\n\n---\n\n## Getting Help\n\n1. **Check Logs**\n   ```bash\n   # Backend\n   npm run dev  # Look for error messages\n   \n   # Frontend\n   npm run dev  # Check browser console\n   ```\n\n2. **Search Issues**\n   -
